
# Sistema de Gerenciamento de Biblioteca  

## Sobre o projeto

É uma aplicação projetada para administrar as operações diárias de uma biblioteca. 
Ele permite o cadastro e remoção de livros, empréstimos e vendas dos mesmos, além de facilitar a busca por títulos disponíveis. 
O sistema pode incluir funcionalidades como gerenciamento de estoque, cadastro de clientes, contratação e desligamento de Funcionários, 
controle de serviços feitos na Biblioteca, cargos diversos de Funcionários(explorando enums). Ideal para a prática de conceitos de 
orientação a objetos, lógica de programação, SOLID, estruturas de dados, interfaces gráficas e gerenciamento de banco de dados.
